# Firelight prototype archive

This directory preserves the standalone HTML/CSS/JavaScript prototype exactly as
it existed at checkpoint commit `98ff7fc`. It is reference material for the
platform rebuild, not production source.

The archive contains the original landing/auth experience, campsite dashboard,
curriculum map, Blink and Morse lessons, Pages runtime config function, headers,
and local Supabase development config. Known prototype shortcuts and defects are
intentionally not carried into the React application.

The four kit renders remain at the repository root because the new Vite build
imports them as versioned application assets. The original favicons are copied
unchanged through `public/`.
